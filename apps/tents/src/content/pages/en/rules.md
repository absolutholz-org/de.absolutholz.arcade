# Tents & Trees Rules

Tents & Trees is a classic camping logic puzzle played on a grid filled with trees and bordered by numeric clues.

## Objective

Pitch exactly one tent for every tree in the forest according to these three rules:

1. **One Tent per Tree:** Every tree must have exactly one tent pitched orthogonally adjacent to it (horizontally or vertically, never diagonally). A tent can only be attached to one tree, even if it touches multiple trees.
2. **No Touching Tents:** Tents may never touch each other—not horizontally, vertically, or diagonally.
3. **Row & Column Numbers:** The number at the edge of each row and column specifies the **exact number of tents** that must be pitched in that line.

## How to Play

- **Click or Tap:** Click an empty tile to cycle through Tent, Grass, and Empty states, or place your selected tool.
- **Right-Click / Grass Tool:** Right-click an empty tile to place Grass when you deduce that no tent can be pitched there.
- **Auto-Grass Helper:** When enabled in settings, placing a tent automatically places grass around its 8 surrounding tiles. Additionally, when a row or column reaches its required tent count, remaining empty tiles can be automatically filled with grass.

## Keyboard Controls

You can navigate the forest campsite completely using your keyboard:

| Key | Action |
| --- | --- |
| **Arrow Keys** | Move focus between cells on the grid |
| **Space** / **Enter** | Cycle cell state (Empty → Tent → Grass → Empty) |
| **T** | Place or toggle a Tent |
| **G** / **X** | Place or toggle Grass |
| **Backspace** / **Delete** | Clear cell mark |
| **Z** / **U** *(or Ctrl/⌘+Z)* | Undo previous move |
| **Y** *(or Ctrl/⌘+Shift+Z)* | Redo undone move |
| **Esc** / **P** | Pause or resume the game |
