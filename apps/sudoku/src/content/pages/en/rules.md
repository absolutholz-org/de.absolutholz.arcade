# How to Play Sudoku

## Objective

Fill the 9×9 grid with digits from 1 to 9 so that each column, each row, and each of the nine 3×3 subgrids contain all digits without repetition.

## Rows

Every row must contain the numbers 1 to 9, without duplicates.

## Columns

Every column must contain the numbers 1 to 9, without duplicates.

## 3×3 Blocks

Every 3×3 block must contain the numbers 1 to 9, without duplicates.

> **Using Notes:** Turn on Notes mode to write down candidate possibilities in empty cells.
