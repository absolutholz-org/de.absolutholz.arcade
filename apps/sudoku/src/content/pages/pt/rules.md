# Regras do Sudoku

## Objetivo

Preencha a grade 9×9 com dígitos de 1 a 9 para que cada coluna, linha e cada um dos nove blocos 3×3 contenham todos os números sem repetição.

## Linhas

Cada linha deve conter os números de 1 a 9, sem repetições.

## Colunas

Cada coluna deve conter os números de 1 a 9, sem repetições.

## Blocos 3×3

Cada bloco 3×3 deve conter os números de 1 a 9, sem repetições.

> **Usar anotações:** Ative o modo de anotações para registrar os candidatos possíveis nas células vazias.
