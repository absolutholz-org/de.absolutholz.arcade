# Net Rules

Net (also known as *Netwalk* or *Network*) is a classic connection puzzle played on a grid of network cables, terminals, and a central power server.

## Objective

Rotate the tiles on the grid so that **every single computer terminal and wire is connected to the central server**:

1. **Connect Everything:** Every node on the grid must receive power from the central server via an unbroken path of matching cable ports.
2. **No Leaking Ports:** In a completed network, there are zero open wires pointing off the board or into mismatched adjacent walls.
3. **Instant Victory:** As soon as all tiles are powered and all cables connect cleanly, the network comes online and you win!

## Grid Dimensions & Difficulties

- **Easy (5×5):** 25 tiles — A compact local network, great for warm-ups and beginners.
- **Medium (7×7):** 49 tiles — Standard office network challenge with branching subnets.
- **Hard (9×9):** 81 tiles — Dense enterprise network requiring careful routing.
- **Expert (11×11):** 121 tiles — Large-scale telecom backbone puzzle with deep branch hierarchies.

## Wire Shapes & Tile Types

- **Root Server:** The pulsing central server that provides power to the entire grid.
- **Terminal (Endpoint):** A computer with a single connection port.
- **Straight Cable:** Connects two opposite sides (North/South or East/West).
- **Corner Cable:** A 90-degree bend connecting two adjacent sides (e.g. North/East).
- **T-Junction:** A 3-way splitter connecting three directions.
- **Cross:** A 4-way intersection connecting North, South, East, and West.

## Gameplay & Controls

- **Mouse / Touch:** Click or tap any tile to rotate it **90° clockwise**. Right-click or long-press to **lock/unlock** a tile.
- **Locking:** Locked tiles cannot be rotated accidentally until unlocked, allowing you to secure solved sections of your network.

## Keyboard Navigation

| Key | Action |
| --- | --- |
| **Arrow Keys** | Navigate the focus cursor across the network grid |
| **Space** / **Enter** | Rotate the focused tile 90° clockwise |
| **Shift + Space** / **Shift + Enter** | Rotate the focused tile 90° counter-clockwise |
| **L** / **Alt + Click** | Lock / unlock the focused tile |
| **Z** / **U** *(or Ctrl/⌘+Z)* | Undo the last rotation |
| **Y** *(or Ctrl/⌘+Shift+Z)* | Redo the last undone rotation |
| **P** | Pause / resume the timer |
