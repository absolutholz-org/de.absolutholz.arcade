# Net-Regeln

Net (auch bekannt als *Netwalk* oder *Network*) ist ein klassisches Verbindungsrätsel auf einem Raster aus Netzwerkkabeln, Computer-Terminals und einem zentralen Server.

## Ziel des Spiels

Drehe die Kacheln auf dem Spielfeld so, dass **jeder einzelne Computer und jedes Kabel mit dem zentralen Server verbunden ist**:

1. **Vollständige Verbindung:** Jeder Knoten im Gitter muss über durchgehende Kabelverbindungen mit dem Hauptserver verbunden sein.
2. **Keine offenen Enden:** Im fertigen Netzwerk gibt es keine offenen Kabelenden, die ins Leere oder gegen eine Wand laufen.
3. **Sofortiger Sieg:** Sobald alle Kacheln mit Strom versorgt sind, geht das gesamte Netzwerk online und du hast gewonnen!

## Schwierigkeitsstufen

- **Einfach (5×5):** 25 Kacheln — Kompaktes Heimnetzwerk, perfekt zum Kennenlernen.
- **Mittel (7×7):** 49 Kacheln — Klassische Büro-Netzwerk-Herausforderung.
- **Schwer (9×9):** 81 Kacheln — Dichtes Unternehmensnetzwerk mit vielen Verzweigungen.
- **Experte (11×11):** 121 Kacheln — Großes Backbone-Netzwerk für anspruchsvolle Knobler.

## Kacheltypen

- **Hauptserver:** Der pulsierende Server im Zentrum, der das Netzwerk speist.
- **Terminal (Endpunkt):** Ein Computer-Arbeitsplatz mit einem einzelnen Anschluss.
- **Gerade Leitung:** Verbindet zwei gegenüberliegende Seiten.
- **Ecke (Kurve):** 90-Grad-Biegung zwischen zwei benachbarten Seiten.
- **T-Stück (Verteiler):** Dreifach-Verzweigung.
- **Kreuzung:** Vierfach-Verbindung in alle vier Himmelsrichtungen.

## Tastatursteuerung

| Taste | Aktion |
| --- | --- |
| **Pfeiltasten** | Cursor über das Raster bewegen |
| **Leertaste** / **Enter** | Kachel im Uhrzeigersinn um 90° drehen |
| **Umschalt + Leertaste/Enter** | Kachel gegen den Uhrzeigersinn um 90° drehen |
| **L** / **Alt + Klick** | Kachel sperren / entsperren |
| **Z** / **U** *(oder Strg/⌘+Z)* | Letzte Drehung rückgängig machen |
| **Y** *(oder Strg/⌘+Umschalt+Z)* | Letzte Drehung wiederholen |
| **P** | Pause / Fortsetzen |
