# Règles de Net

Net (également connu sous le nom de *Netwalk*) est un jeu de réflexion classique dans lequel vous devez reconstituer un réseau informatique complet.

## Objectif

Faites pivoter les tuiles de la grille pour que **chaque terminal et chaque câble soient reliés au serveur central** :

1. **Tout connecter :** Chaque nœud de la grille doit être alimenté par le serveur central grâce à des connexions ininterrompues.
2. **Aucun câble dans le vide :** Dans un réseau terminé, aucun port ouvert ne doit pointer vers l'extérieur ou vers un mur.
3. **Victoire instantanée :** Dès que tous les terminaux sont sous tension et le réseau continu, vous gagnez la partie !

## Niveaux de difficulté

- **Facile (5×5) :** 25 tuiles — Idéal pour débuter.
- **Moyen (7×7) :** 49 tuiles — Défi classique d'entreprise.
- **Difficile (9×9) :** 81 tuiles — Réseau dense avec de nombreux embranchements.
- **Expert (11×11) :** 121 tuiles — Vaste grille backbone pour les experts.

## Types de câbles

- **Serveur central :** Le serveur d'alimentation principal situé au centre.
- **Terminal (Bout de ligne) :** Un ordinateur avec un seul port.
- **Ligne droite :** Relie deux côtés opposés.
- **Coude (Angle) :** Virage à 90 degrés.
- **Té de dérivation :** Répartiteur à trois voies.
- **Croisement :** Carrefour à quatre voies.

## Commandes au clavier

| Touche | Action |
| --- | --- |
| **Flèches** | Déplacer le curseur sur la grille |
| **Espace** / **Entrée** | Faire pivoter la tuile de 90° dans le sens horaire |
| **Maj + Espace / Entrée** | Faire pivoter la tuile de 90° dans le sens anti-horaire |
| **L** / **Alt + Clic** | Verrouiller / déverrouiller une tuile |
| **Z** / **U** *(ou Ctrl/⌘+Z)* | Annuler la rotation |
| **Y** *(ou Ctrl/⌘+Maj+Z)* | Rétablir la rotation |
| **P** | Mettre en pause ou reprendre |
