# Declaração de Acessibilidade para Arcade Web App

## O Nosso Objetivo

O Arcade Web App tem o compromisso de garantir a acessibilidade digital para todos os utilizadores, independentemente de suas capacidades. O nosso objetivo é alcançar a conformidade total com as normas **WCAG 2.2 Nível AA** e **BITV 2.0**.

## Estado Atual

Atualmente, estamos numa fase de desenvolvimento e melhoria contínua. Estamos a dar prioridade à acessibilidade na nossa arquitetura central desde o primeiro dia.

### A Nossa Abordagem ao Design Inclusivo

Em vez de aplicar remendos a um site inacessível, estamos a construir a nossa fundação em componentes pensados primeiramente para a acessibilidade (Accessibility-First):

- **Átomos de Alta Fidelidade**: Desenvolvemos elementos de interface — como os nossos banners de estado e interruptores interativos — que usam codificação redundante (ícones + texto) e dimensionamento relativo (unidades `rem`) para garantir que funcionam para todos.
- **Integridade para Leitores de Ecrã**: Cada elemento interativo é construído com estruturas semânticas nativas e funções ARIA apropriadas para garantir clareza para tecnologias de assistência.
- **Layouts Resilientes**: Auditamos os nossos designs para o modo de cores forçadas (Forced Colors) e capacidades de refluxo (Reflow) para apoiar os utilizadores que precisam de alto contraste ou alta ampliação de texto.
