# @arcade/bridges — Local Agent Invariants

- **Engine (`src/engine/`):** 100% framework-free. Guarantee single connected planar graph with valid single/double bridge connectivity across 5 tiers: `beginner` (6×6), `easy` (8×8), `medium` (10×10), `hard` (14×14), `expert` (18×18). Support Standard (timed) and Zen (untimed) modes plus satisfied/overflow island highlights.
- **Accessibility & Controls:** Implement WAI-ARIA grid navigation (arrow keys + directional bridge building) alongside direct island clicking/raycasting and non-color state cues.
- **Namespaces:** i18n `bridges`; storage `createGameStorage('bridges')`.
