# Règles du jeu Bridges

Bridges (aussi appelé **Hashiwokakero** ou **Ponts**) est un jeu de logique composé d'îles circulaires numérotées.

## Objectif

Relier toutes les îles pour former un **réseau continu unique** respectant ces critères :

1. **Nombre de ponts :** Le chiffre indique le nombre exact de ponts connectés à cette île.
2. **Capacité :** Entre deux îles adjacentes, on peut placer au maximum **deux ponts** (simple ou double).
3. **Directions :** Les ponts sont strictement horizontaux ou verticaux.
4. **Pas de croisements :** Les ponts ne peuvent ni se croiser ni traverser d'autres îles.
5. **Réseau connexe :** Toutes les îles doivent être interconnectées à la fin.

## Comment jouer

- **Sélectionner une île :** Cliquez sur une île pour démarrer la connexion.
- **Relier :** Cliquez sur une île alignée pour poser un pont. Un second clic en fait un pont double, un troisième le supprime (`0 -> 1 -> 2 -> 0`).
- **Aides visuelles :** Activez l'indicateur d'îles complètes (vert) ou d'îles dépassées (rouge) dans les réglages.
- **Mode Zen :** Désactivez le chronomètre pour jouer en toute sérénité.
