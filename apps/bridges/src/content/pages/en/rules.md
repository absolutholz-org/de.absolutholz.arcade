# Bridges Rules

Bridges (also known as **Hashiwokakero**) is an engaging logic puzzle played on a grid of circular islands.

## Objective

Connect all islands with bridges to form a **single continuous network** such that:

1. **Island Numbers:** The number inscribed on each island indicates how many bridges must connect to it.
2. **Bridge Capacity:** Between any two adjacent islands, you may place at most **two bridges** (single or double bridge).
3. **Orthogonal Paths:** Bridges must run strictly horizontally or vertically between islands.
4. **No Crossings:** Bridges must not cross each other or pass through other islands.
5. **Single Connected Network:** When complete, every island must be reachable from every other island.

## How to Play

- **Select Island:** Click or tap an island to select it as the connection start.
- **Connect / Cycle:** Click a collinear neighboring island to place a single bridge. Clicking again upgrades it to a double bridge, and a third click removes the bridge (cycling `0 -> 1 -> 2 -> 0`).
- **Assist Modes:** Use the settings menu to toggle highlighting for satisfied islands (green) or overflow islands (red).
- **Zen Mode:** Disable the timer in settings to solve relaxing puzzles at your own pace without pressure.

## Keyboard Controls

| Key | Action |
| --- | --- |
| **Arrow Keys** | Navigate focus between islands |
| **Space** / **Enter** | Select focused island or connect to previously selected island |
| **Escape** | Deselect active island |
| **Z** / **U** | Undo previous move |
| **Y** / **R** | Redo undone move |
| **P** | Pause / resume puzzle |
