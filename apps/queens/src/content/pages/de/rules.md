# Queens Regeln

Queens ist ein faszinierendes Logikrätsel auf einem N×N Spielfeld, das in N unterschiedliche Farbzonen unterteilt ist.

## Ziel des Spiels

Platziere genau **N Kronen** auf dem Feld, sodass folgende Bedingungen erfüllt sind:

1. **Zeilen & Spalten:** Jede Zeile und jede Spalte enthält genau **eine Krone**.
2. **Farbzonen:** Jede farbige Zone enthält genau **eine Krone**.
3. **Königsabstand:** Keine zwei Kronen dürfen sich horizontal, vertikal oder diagonal berühren.

## Steuerung & Tipps

- **Markierung (X):** Klicke oder tippe auf ein leeres Feld, um ein **X** zu setzen und anzuzeigen, dass dort keine Krone sein kann.
- **Krone:** Doppelklicke oder wechsle in den Kronenmodus, um eine Krone zu setzen.
- **Wisch-Markierung:** Ziehe über mehrere leere Felder, um sie schnell mit X zu markieren.
- **Auto-Kreuz:** Aktiviere den Auto-Kreuz Assistenten, um beim Setzen einer Krone automatisch die Zeile, Spalte und Nachbarfelder mit X zu versehen.

## Tastaturkürzel

Beim Spielen mit Tastatur oder Screenreader stehen direkte Tastenkombinationen zur Verfügung:

| Taste | Aktion |
| --- | --- |
| **Pfeiltasten** | Fokus auf benachbarte Spielfelder bewegen |
| **Pos1 / Ende** | Zum Anfang oder Ende der aktuellen Zeile springen |
| **Leertaste** / **Eingabe** | Feldzustand gemäß aktivem Modus umschalten |
| **X** / **M** | Direkt ein X setzen oder entfernen |
| **C** / **Q** | Direkt eine Krone setzen oder entfernen |
| **Rücktaste** / **Entf** | Aktuelles Feld leeren |
| **Z** / **U** | Letzten Zug rückgängig machen |
| **Y** / **R** *(mit Strg oder ⌘)* | Rückgängig gemachten Zug wiederholen |
| **Esc** / **P** | Spiel pausieren oder fortsetzen |
