## Spielziel

Färbe jede Region der Karte mit nur **4 Farben** (`●` Koralle, `▲` Bernstein, `■` Smaragd, `◆` Kobalt), sodass **keine zwei angrenzenden Regionen dieselbe Farbe haben**.

1. **Nur gemeinsame Kanten:** Zwei Regionen grenzen nur dann aneinander, wenn sie eine waagerechte oder senkrechte Kante teilen. Regionen, die sich nur an einer diagonalen Ecke berühren, **dürfen** dieselbe Farbe tragen.
2. **Feste Start-Hinweise:** Regionen mit einem Eck-Pin oder Innenring sind fest vorgegeben und können nicht verändert werden.
3. **Eindeutige Lösung:** Jede generierte Karte ist mathematisch auf genau **eine eindeutige Vier-Färbung** geprüft.

## Steuerung

### Tippen / Klicken
- Wähle eines der **4 Farbfelder**, den **Radierer** oder den **Notizmodus** in der Werkzeugleiste und klicke oder tippe auf eine freie Region.

### Klassisches Drag-to-Copy
- **Farbe kopieren:** Ziehe von einer gefärbten Region in eine freie Region, um die Farbe zu übernehmen.
- **Farbe löschen:** Ziehe vom Rand außerhalb der Karte in eine freie Region, um sie zu leeren.
- **Kandidaten-Punkte:** Ziehe mit gedrückter rechter Maustaste (oder im **Notizmodus**) von einer gefärbten in eine ungefärbte Region, um einen Kandidaten-Punkt umzuschalten.

### Tastaturkürzel
- **Pfeiltasten:** Fokus auf angrenzende Regionen bewegen.
- **1–4:** Farbe zuweisen (oder Kandidat im Notizmodus umschalten).
- **Umschalt + 1–4:** Kandidaten-Punkt direkt umschalten.
- **P:** Notizmodus umschalten.
- **Rücktaste / Entf / 0:** Fokussierte Region leeren.
- **Z / Y:** Rückgängig / Wiederholen.
- **Esc:** Spiel pausieren.
