## Objetivo

Pinte todas as regiões do mapa usando apenas **4 cores** (`●` Coral, `▲` Âmbar, `■` Esmeralda, `◆` Cobalto) de modo que **nenhuma região compartilhe a mesma cor com uma região vizinha**.

1. **Apenas bordas compartilhadas:** Duas regiões são vizinhas somente quando compartilham uma aresta horizontal ou vertical. Regiões que se tocam apenas em um canto diagonal **podem** ter a mesma cor.
2. **Pistas bloqueadas:** Regiões marcadas com um pino/anel são pistas iniciais fixas e não podem ser apagadas.
3. **Solução única:** Todo mapa gerado é verificado matematicamente para garantir **uma única solução válida**.

## Controles

### Modo Toque / Clique
- Escolha uma das **4 cores**, a **Borracha** ou ative o **Modo Lápis** na barra de ferramentas e clique ou toque em qualquer região desbloqueada.

### Arrastar para Copiar clássico
- **Copiar cor:** Arraste de uma região colorida para uma região desbloqueada para copiar sua cor.
- **Apagar cor:** Arraste de fora da borda do mapa para uma região desbloqueada para limpá-la.
- **Pontos candidatos:** Arraste com o botão direito (ou arraste com o **Modo Lápis** ativo) de uma região colorida para uma região vazia para alternar um ponto candidato.

### Atalhos de teclado
- **Setas:** Mover o foco entre regiões vizinhas.
- **1–4:** Aplicar cor (ou alternar candidato no Modo Lápis).
- **Shift + 1–4:** Alternar ponto candidato diretamente.
- **P:** Alternar Modo Lápis.
- **Backspace / Delete / 0:** Apagar a região em foco.
- **Z / Y:** Desfazer / Refazer.
- **Esc:** Pausar o jogo.
