# Star Battle Rules

Star Battle is an elegant logic puzzle played on an N×N board divided into N distinct colored regions.

## Objective

Place exactly **N stars** on the board such that:

1. **Rows & Columns:** Every row and every column contains exactly **one star**.
2. **Colored Regions:** Every colored region contains exactly **one star**.
3. **Non-Adjacency Rule:** No two stars may touch each other horizontally, vertically, or diagonally.

## How to Play

- **Mark (X):** Click or tap an empty square to mark it with an **X** to indicate that no star can sit there.
- **Star:** Double-click or switch to Star Mode to place a star.
- **Drag to Eliminate:** Click and drag across empty squares to rapidly mark entire rows or zones with X.
- **Auto-Cross:** Enable the Auto-Cross helper to automatically place X marks in the row, column, and 8 neighbor cells whenever you place a star.

## Keyboard Shortcuts

If you play with a keyboard or screen reader, you can navigate and solve the puzzle using direct shortcuts:

| Key | Action |
| --- | --- |
| **Arrow Keys** | Move focus to neighboring squares across the grid |
| **Home / End** | Jump to the start or end of the current row |
| **Space** / **Enter** | Toggle square state using the active mode |
| **X** / **M** | Directly place or remove an X mark |
| **S** / **C** / **Q** | Directly place or remove a Star token |
| **Backspace** / **Delete** | Clear the current square back to empty |
| **Z** / **U** | Undo the previous move |
| **Y** / **R** *(with Ctrl or ⌘)* | Redo the undone move |
| **Esc** / **P** | Pause or resume the puzzle |
