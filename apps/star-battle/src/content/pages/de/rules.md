# Sternenschlacht Regeln

Sternenschlacht ist ein faszinierendes Logikrätsel auf einem N×N Spielfeld, das in N unterschiedliche Farbzonen unterteilt ist.

## Ziel des Spiels

Platziere genau **N Sterne** auf dem Feld, sodass folgende Bedingungen erfüllt sind:

1. **Zeilen & Spalten:** Jede Zeile und jede Spalte enthält genau **einen Stern**.
2. **Farbzonen:** Jede farbige Zone enthält genau **einen Stern**.
3. **Abstandsregel:** Keine zwei Sterne dürfen sich horizontal, vertikal oder diagonal berühren.

## Steuerung & Tipps

- **Markierung (X):** Klicke oder tippe auf ein leeres Feld, um ein **X** zu setzen und anzuzeigen, dass dort kein Stern sein kann.
- **Stern:** Doppelklicke oder wechsle in den Sternenmodus, um einen Stern zu setzen.
- **Wisch-Markierung:** Ziehe über mehrere leere Felder, um sie schnell mit X zu markieren.
- **Auto-Kreuz:** Aktiviere den Auto-Kreuz Assistenten, um beim Setzen eines Sterns automatisch die Zeile, Spalte und Nachbarfelder mit X zu versehen.

## Tastaturkürzel

Beim Spielen mit Tastatur oder Screenreader stehen direkte Tastenkombinationen zur Verfügung:

| Taste | Aktion |
| --- | --- |
| **Pfeiltasten** | Fokus auf benachbarte Spielfelder bewegen |
| **Pos1 / Ende** | Zum Anfang oder Ende der aktuellen Zeile springen |
| **Leertaste** / **Eingabe** | Feldzustand gemäß aktivem Modus umschalten |
| **X** / **M** | Direkt ein X setzen oder entfernen |
| **S** / **C** / **Q** | Direkt einen Stern setzen oder entfernen |
| **Rücktaste** / **Entf** | Aktuelles Feld leeren |
| **Z** / **U** | Letzten Zug rückgängig machen |
| **Y** / **R** *(mit Strg oder ⌘)* | Rückgängig gemachten Zug wiederholen |
| **Esc** / **P** | Spiel pausieren oder fortsetzen |
