# Hashiwokakero Spielregeln

Hashiwokakero (oft einfach **Brücken** genannt) ist ein faszinierendes Logikrätsel auf einem Gitter aus Inseln.

## Ziel des Spiels

Verbinde alle Inseln so mit Brücken, dass ein **einziges zusammenhängendes Netz** entsteht:

1. **Inselzahlen:** Die Zahl auf jeder Insel gibt an, wie viele Brücken an ihr anliegen müssen.
2. **Brückenkapazität:** Zwischen zwei Inseln dürfen maximal **zwei Brücken** verlaufen (einfach oder doppelt).
3. **Orthogonale Wege:** Brücken dürfen nur streng horizontal oder vertikal verlaufen.
4. **Keine Kreuzungen:** Brücken dürfen einander weder kreuzen noch andere Inseln durchqueren.
5. **Einheitliches Netzwerk:** Am Ende müssen alle Inseln miteinander verbunden sein.

## Spielweise

- **Insel wählen:** Klicke auf eine Insel, um sie als Startpunkt auszuwählen.
- **Verbinden / Zyklus:** Klicke auf eine benachbarte Insel in derselben Reihe oder Spalte, um eine Brücke zu bauen. Ein weiterer Klick verdoppelt die Brücke, ein dritter entfernt sie wieder (`0 -> 1 -> 2 -> 0`).
- **Hilfen:** In den Einstellungen kannst du optische Markierungen für erfüllte Inseln (grün) und überfüllte Inseln (rot) aktivieren.
- **Zen-Modus:** Schalte die Zeitmessung ab, um ganz ohne Zeitdruck zu rätseln.

## Tastatursteuerung

| Taste | Aktion |
| --- | --- |
| **Pfeiltasten** | Fokus zwischen Inseln bewegen |
| **Leertaste** / **Enter** | Insel auswählen oder verbinden |
| **Escape** | Auswahl aufheben |
| **Z** / **U** | Zug rückgängig machen |
| **Y** / **R** | Zug wiederholen |
| **P** | Spiel pausieren / fortsetzen |
