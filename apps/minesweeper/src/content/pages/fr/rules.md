# Règles du Démineur

## Objectif

Révélez toutes les cases sûres du plateau sans toucher aux mines cachées.

## Chiffres

Un chiffre indique combien de mines se trouvent dans les 8 cases adjacentes.

## Drapeaux

Faites un clic droit ou appuyez sur F pour poser un drapeau sur les mines supposées.

## Accords

Double-cliquez sur un chiffre lorsque tous ses drapeaux voisins sont posés pour révéler le reste.
