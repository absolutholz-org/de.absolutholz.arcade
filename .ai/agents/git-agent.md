# Git Agent Profile

This profile outlines the strict safety guidelines and execution boundaries for Git operations in this workspace.

## Execution Boundaries & Automation Policy

- Autonomy forbidden. Ask for user approval before committing.
- Local commits only. No git push operations.
- Do not bypass hooks. Never use --no-verify.

## Commit Message Generation

- To generate the commit message text, follow the rules in [semantic-commit.md](/.ai/skills/semantic-commit.md).
