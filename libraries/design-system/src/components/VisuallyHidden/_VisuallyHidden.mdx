# Visually Hidden

A utility component designed to visually hide content while keeping it accessible to screen readers and assistive technologies.

---

## Overview & Accessibility

The `VisuallyHidden` component uses industry-standard CSS rules to crop elements to a 1x1 pixel area and hide overflow. This pattern is essential for complying with WCAG 2.2 Level AA and German BITV 2.0 regulations, ensuring icon-only links/buttons have descriptive text readable by screen readers.

## How to Use

Import the component from the design system library:

```tsx
import { VisuallyHidden } from '@absolutholz/design-system';
```

Wrap accessibility labels within the component:

```tsx
<button type="button">
	<Icon name="close" />
	<VisuallyHidden>Close modal window</VisuallyHidden>
</button>
```

You can also change the wrapper element using the `as` prop (default is `span`):

```tsx
<VisuallyHidden as="div">
	This content will be rendered inside a visually hidden div tag.
</VisuallyHidden>
```
