# Spacing

This document outlines our design system's spacing scale strategy, layout tokens, and compilation utilities.

---

## Spacing Strategy

Our layout engine utilizes **CSS Custom Properties** to dynamically scale spacing dimensions depending on screen size. This enables responsive scaling of major spacing tokens using multi-axis media queries. Under the hood, developers still consume a type-safe compiler utility.

## Compiler Utility

Developers must formulate margin, padding, or gap styles using the `space` helper function imported from `@absolutholz/design-system` rather than hardcoding static pixel or REM strings.

### Function Signature

```tsx
import { space, type SpacingKey } from '@absolutholz/design-system';

// Compile a single margin value
const marginSingle = space('md'); // returns: "1rem"

// Compile shorthand values (up to 4 keys)
const paddingShorthand = space('md', 'lg'); // returns: "1rem 1.5rem"
const borderShorthand = space('xs', 'none', 'sm', 'lg'); // returns: "0.5rem 0rem 0.75rem 1.5rem"
```

### Emotion/CSS Example

```tsx
import styled from '@emotion/styled';
import { space } from '@absolutholz/design-system';

export const Card = styled.div`
	padding: ${space('md', 'lg')};
	margin-bottom: ${space('xl')};
	display: flex;
	gap: ${space('xs')};
`;
```
