# @arcade/lib-ui — Local Agent Invariants

- **Authoritative Inventory:** Audit [`CATALOG.md`](/libraries/ui/CATALOG.md) before adding or modifying any component. Keep `CATALOG.md` in sync with `src/index.ts`.
- **Component Matrix & Exports:** Follow [`component-development`](/.ai/../libraries/ui/.ai/skills/component-development/SKILL.md) (folder per component, `_ComponentName.*` files, `index.ts` single-component re-export, <= 200 lines per view, no `...rest` spread, named exports, `Omit<..., 'style'>`, `S` styled namespace) and [`codebase-structure`](/.ai/skills/codebase-structure/SKILL.md).
- **Native Web & `browserslist` SSOT:** Treat [`.browserslistrc`](/.browserslistrc) as the single source of truth for feature support—prefer native HTML, CSS, and Web APIs supported by those targets over third-party libraries or polyfills, and consult [`modern-web-guidance`](/.agents/skills/modern-web-guidance/SKILL.md) before implementing interactive UI, dialogs/popovers, animations, theming, or forms.
- **Accessibility & Styling:** Enforce BITV 2.0 / BFSG / WCAG 2.2 AA + Forced Colors Mode ([`accessibility-engineering`](/.ai/skills/accessibility-engineering/SKILL.md)) and zero-runtime Linaria with `rem` units + `data-*` selectors ([`linaria-styling`](/.ai/skills/linaria-styling/SKILL.md)).
- **Storybook:** Follow [`storybook-documentation`](/libraries/ui/.ai/skills/storybook-documentation/SKILL.md). Only place stories under existing Storybook categories (`Foundations/`, `Components/`, `Layouts/`, `Templates/`, `System Pages/`); ask the user before inventing new root categories.
