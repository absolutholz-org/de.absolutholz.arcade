# StaticPageLayout

`StaticPageLayout` wraps `PageLayout` for content collections, game rules, guides, and informational subpages.

It automatically injects a W3C APG compliant `Breadcrumb` trail positioned in a dedicated landmark above `<main id="main-content">`:

- **Game subpages**: `[Arcade Logo] / [Game Title] / [Page Title]`
- **Hub subpages**: `[Arcade Logo] / [Page Title]`

## Usage

```astro
---
import StaticPageLayout from '@arcade/lib-ui/layouts/StaticPageLayout/StaticPageLayout.astro';
---

<StaticPageLayout
  title="Sudoku Rules"
  lang="en"
  appTitle="Sudoku"
  basePath="sudoku"
  currentSlug="rules"
>
  <slot />
</StaticPageLayout>
```

## Props

- `title`: Subpage title string (used in breadcrumbs and document title).
- `description`: Optional meta description.
- `lang`: Supported language code (`'en'`, `'de'`, etc.).
- `appTitle`: Application name (optional, defaults to common app title).
- `appHomeHref`: Home URL for the game or hub.
- `currentSlug`: Active route slug.
- `basePath`: Subdirectory route prefix.
- `canonicalBase`: Origin URL for canonical links.
- `manifestHref`: Web app manifest URL.
- `headerVariant`: Header display mode (`'standard'`, `'minimal'`, or `'none'`).
- `breadcrumbItems`: Custom breadcrumb items if overriding automatic hierarchical trail.
