# Border Radius

This document outlines our design system's border radius scale strategy, tokens, and type-safe compilation utility.

## Compiler Utility

Developers must formulate border-radius styles using the `radius` helper function imported from `@arcade/lib-ui/styles/radius` rather than hardcoding static pixel or CSS string values.

### Function Signature

```tsx
import {
	radius,
	type RadiusKey,
} from '@arcade/lib-ui/styles/radius';

// Compile a single border radius value
const roundedCorner = radius('md'); // returns: "var(--radius-md)"

// Compile shorthand values (up to 4 keys for top-left, top-right, bottom-right, bottom-left)
const roundedShorthand = radius('md', 'none'); // returns: "var(--radius-md) var(--radius-none)"
```

### Linaria Example

```tsx
import { css } from '@linaria/core';
import { radius } from '@arcade/lib-ui/styles/radius';

export const card = css`
	border-radius: ${radius('md')};
	background-color: var(--color-surface);
	border: 1px solid var(--color-container-2);
`;

export const pillButton = css`
	border-radius: ${radius('pill')};
`;
```
